New to Python? Try each example in the Python Playground. It runs in your browser, so there's nothing to install.

Where to go next

Reading is a start, but writing code is how it sticks. The playground has five short lessons that build on each other, and each one checks your answer and gives you a hint if it's not quite right:

  1. Variables and types
  2. Conditionals
  3. Loops
  4. Lists and dictionaries
  5. Functions

After that, try a small project of your own, like a tip calculator, a to-do list or a number-guessing game. When you're ready to install Python on your own computer, start at python.org and the official Python tutorial.
